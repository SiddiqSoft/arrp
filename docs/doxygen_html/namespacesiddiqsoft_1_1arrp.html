Indicates various error conditions that can occur during pool operations.

Enumerator

Reason for releasing a resource back to the pool.

Indicates why a resource is being returned to the pool. Valid resources are reused; abandoned resources are discarded.

Enumerator

◆ resource_pool_limits

enum siddiqsoft::arrp::resource_pool_limits : uint8_t

Resource pool capacity limits and defaults.

Defines the minimum, default, and maximum configured capacity values for resource pools. The configured capacity is reported in pool statistics; it is not an insertion limit.

Note
Values selected here have no special meaning and are only guides.
MinimumCapacity: Smallest allowed pool size (1 resource)
DefaultCapacity: Default pool size when not specified (8 resources)
MaxCapacity: Largest allowed pool size (255 resources)
