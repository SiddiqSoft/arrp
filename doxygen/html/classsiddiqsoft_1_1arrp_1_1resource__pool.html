void siddiqsoft::arrp::resource_pool< T, SRT >::return_to_pool ( T && item,
bool isvalid )
inline

Returns a resource to the pool.

Called by scoped_resource destructor to return the resource to the pool. If the resource is valid, it's added back to the pool for reuse. If invalid, it's discarded and the abandoned counter is incremented.

Parameters
itemThe resource to return (moved)
isvalidWhether the resource is valid and should be reused
Returns
std::expected<void, pool_error> indicating success or error
Note
Thread-safe: Uses exclusive lock
Increments appropriate counter (valid_returns or invalid_returns)
Decrements checkout counter
Returns if pool is shutting down
This method MUST be invoked to "return" the resource back to pool otherwise the accounting and resource management will not work properly!
